# Architecture Decision Records

Status flow: `Proposed` (drafted by an agent from the owner's decision summary) -> `Accepted` (owner approves) -> possibly `Superseded`.
Only the owner moves an ADR to `Accepted`. Agents never accept their own drafts.

Later ADRs (personal data protection, message retention, search, media, notifications, reputation...) are written in the phase that needs them.
